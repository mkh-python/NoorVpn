# NoorVpn

بات تلگرام برای فروش و مدیریت اشتراک VPN، همراه پنل مدیریت و Mini App.

**نسخهٔ فعلی: 0.1.0-rc.3 — نامزد انتشار و نیازمند پذیرش نهایی.** اتصال واقعی به 3x-ui 3.11.0 و عملیات آزمایشی ساخت، تغییر، ترافیک و حذف بررسی شده است. پرداخت واقعی، همهٔ پنل‌های دیگر و نصب کامل از صفر هنوز تأیید نشده‌اند. گزارش دقیق در [TEST_REPORT.md](TEST_REPORT.md) است.

## نصب

Ubuntu 24.04 یا 26.04، دسترسی root، حداقل ۲ گیگابایت فضای آزاد و یک دامنه با رکورد A مستقیم به سرور لازم است. در این نسخه رکورد AAAA دامنهٔ بات را حذف کنید؛ تنظیمات تولیدشده فقط روی IPv4 گوش می‌دهند. سرور با ۲ گیگابایت RAM، در کنار چند سرویس VPN، باید از نظر مصرف حافظه پایش شود.

ابتدا پنل ثنایی سازگار با API جدید را نصب و اینباند و لینک ساب آن را با برنامهٔ کاربر تست کنید. نصب‌کنندهٔ NoorVpn خودِ پنل ثنایی یا اینباند VPN را نصب نمی‌کند.

برای دریافت از گیت‌هاب پس از انتشار مخزن:

```bash
sudo apt-get update
sudo apt-get install -y git
git clone https://github.com/mkh-python/NoorVpn.git
```

سپس:

```bash
cd NoorVpn
bash install.sh check --domain bot.example.com
sudo bash install.sh install \
  --domain bot.example.com \
  --admin 123456789 \
  --local-panel
```

دامنه و آیدی را جایگزین کنید. نصب‌کننده توکن **همین بات جدید** را مخفیانه در ترمینال می‌پرسد. توکن بات یا رمزها را در GitHub، Issue یا چت عمومی قرار ندهید.

`--local-panel` برای اتصال به **3x-ui موجود و دارای API جدید** است؛ پنل VPN دیگری نصب نمی‌کند. اگر پنل روی سرور دیگری است، این گزینه را حذف و پنل را از مدیریت بات تنظیم کنید.

نصب‌کننده PHP-FPM، MySQL و وابستگی‌های لازم را نصب و یک سایت Nginx جدا اضافه می‌کند. سرویس‌های MTG، SoftEther، AWG و X-UI را بازتنظیم نمی‌کند. اشغال‌بودن TCP 443 باعث انتخاب 8443 می‌شود؛ دسترسی بیرونی به آن پورت باید برقرار باشد. سازگاری 8443 با درگاه پرداخت خود را پیش از استفاده بررسی کنید.

نصب مجدد یا ارتقای خودکار هنوز پشتیبانی نمی‌شود؛ نصب‌کننده برای جلوگیری از بازنویسی داده‌ها، نصب قبلی یا ناقص را رد می‌کند. [راهنمای نصب](INSTALL_GUIDE.md) را بخوانید.

## قبل از پاک‌کردن سرور

سورس گیت‌هاب شامل مشتری‌ها، سفارش‌ها، کیف پول‌ها، کلید API، توکن بات، رمز ورود، گواهی‌ها یا تنظیمات اینباند سرور نیست. اگر به این داده‌ها نیاز دارید، بکاپ خصوصی را بیرون از همان سرور نگه دارید. نصب تازه این اطلاعات را از گیت‌هاب بازیابی نمی‌کند.

## اتصال محلی به ثنایی

```bash
sudo bash install.sh discover
```

این دستور فقط پورت و اینباندهای موجود را می‌خواند. هم‌سرور بودن جای احراز هویت را نمی‌گیرد. در نصب با `--local-panel` یک API token اختصاصی با نام NoorVpn ساخته می‌شود؛ توکن‌های دیگر چرخانده نمی‌شوند. اگر این نام از قبل وجود داشته باشد، ساخت توکن جدید متوقف می‌شود.

برای HTTPS، نام گواهی حفظ و اتصال مدیریتی به loopback هدایت می‌شود؛ بررسی SSL خاموش نمی‌شود. لینک عمومی اشتراک کاربران جدا از آدرس مدیریتی است. در افزودن دستی ثنایی، مقدار درخواست‌شده **API Token ثنایی** است؛ رمز پنل وب NoorVpn یا توکن تلگرام را جای آن وارد نکنید.

تنظیم عمومی ساب را در خود ثنایی انجام دهید و پیش از اتصال بات با V2Box/v2ray روی اینترنت مشتری تست کنید. مسیر واسط ساب در [راهنمای اختیاری](docs/changes/subscription-download-route.md) آمده و نصب‌کننده آن را خودکار فعال نمی‌کند.

پس از نصب، مدیر باید در تلگرام `/start` بزند، دسترسی پنل وب را از منوی مدیر فعال کند و محصولات، قیمت‌ها و درگاه‌ها را تنظیم کند. نام کاربری و رمز اولیهٔ وب، عمومی یا ثابت نیست.

## کانال گزارش‌ها

در «گزارشات ربات»، ابتدا لینک عمومی یا دعوت خصوصی و سپس آیدی عددی همان مقصد را وارد کنید. ربات باید ادمین باشد؛ کانال به اجازهٔ ارسال پیام نیاز دارد. لینک دعوت باعث عضویت خودکار ربات نمی‌شود. کانال و گروه عادی به فعال‌بودن انجمن/تاپیک نیاز ندارند؛ گروه‌های انجمنی همچنان از تاپیک پشتیبانی می‌کنند.

## آزمون‌ها

```bash
composer --no-plugins --no-scripts install --no-interaction --no-dev
composer --no-plugins --no-scripts check-platform-reqs --no-dev
python3 -m unittest discover -s tests -v
python3 test_static.py
sudo python3 tests/nginx_smoke.py
```

آزمون دیتابیس فقط در کپی آزمایشی سورس و با MySQL محلی:

```bash
sudo python3 tests/schema_smoke.py
```

این آزمون دیتابیس و کاربر موقت ایجاد و پاک می‌کند؛ روی نسخهٔ تنظیم‌شده اجرا نمی‌شود. آزمون زندهٔ پنل، با گزینهٔ صریح، یک کاربر آزمایشی می‌سازد و در پایان حذف می‌کند:

```bash
sudo php tests/panel_smoke.php \
  --private-config /etc/noorvpn-bootstrap/panel.json \
  --allow-client-mutation
```

## وضعیت امکانات و سورس

PHP و فایل‌های قابل ویرایش موجود در توزیع اولیه حفظ شده‌اند. Mini App و بخشی از رابط اولیه به‌صورت فایل‌های JavaScript ساخته‌شده تحویل شده‌اند؛ پروژهٔ اصلی frontend و تنظیمات build در ورودی موجود نبودند. بازسازی frontend از سورس اصلی هنوز ممکن نیست.

اتصال‌های دیگر موجود در سورس، به معنی تأیید عملکردشان در این نسخه نیست. ساخت بات نمایندگی PHP در مسیر `vpnbot/` در سایت عمومی فعال نمی‌شود و برای انتشار مستقل به بازبینی جدا نیاز دارد.
