# Attribution and source provenance

NoorVpn is a modified distribution of the PHP Telegram VPN-sales bot supplied for this project. Existing code identifies parts of the application as MirzaBot. Original copyright and applicable AGPL license obligations remain in force. The supplied archive did not include a canonical upstream repository URL; none has been invented or substituted.

The included LICENSE is preserved. Composer dependencies carry their own notices/licenses and are installed from composer.lock. Existing third-party assets remain as supplied. Original frontend build sources were not present in the supplied archive; the prebuilt assets are retained and this limitation is documented.

NoorVpn changes include deployment isolation, local panel discovery/setup, webhook authentication, credential handling, migration error handling, transport fixes, tests and documentation.
