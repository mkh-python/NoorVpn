# NoorVpn Implementation Plan

Goal: prepare a reviewable public NoorVpn source distribution and validate against the existing server without disturbing VPN services.
Architecture: retain existing PHP application; add small standalone security/configuration helpers and local discovery CLI; correct installer lifecycle and release tooling.
Tech stack: PHP >=8.2, Python 3, Bash, MySQL, Nginx.
Spec: docs/superpowers/specs/2026-11-17-noorvpn-design.md

## Global constraints
Preserve upstream license. No client or panel database mutations for discovery. Never publish server credentials. No changes to live VPN services.
